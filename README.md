# Приложение для поиска вакансий.
## Описание: 
Веб-приложение на Django, предназначенное для управления email-рассылками. Пользователи могут создавать и редактировать рассылки, сообщения, клиентов, а также просматривать статистику и управлять попытками отправки.
## Возможности:
1) Регистрация, вход и восстановление пароля
2) Управление клиентами рассылок
3) Создание и отправка сообщений
4) Создание и редактирование рассылок
5) Отправка рассылок через интерфейс и командную строку
6) Статистика и история попыток рассылки
7) Ролевой доступ (пользователь / менеджер)
8) Кеширование и оптимизация запросов
## Запуск проекта
1) Клонируйте репозиторий
2) Создайте и активируйте виртуальное окружение
3) Установите зависимости
4) Настройте переменные окружения
5) Выполните миграции и создайте суперпользователя
6) Запустите сервер командой python manage.py runserver
